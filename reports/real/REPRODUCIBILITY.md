# Reproducibility & Gitignored Artifact Inventory

## 1. One-Command Reproduction
```bash
pip install -r requirements.txt
make reproduce   # or: bash run_all.sh (fixed seeds: 42 123 2024)
```
All hyperparameters in Optuna (`scripts/analysis/run_optuna_and_pruning.py`) were tuned **strictly on the validation split** (`12` trials, zero test-set peeking), and the winning configuration (`base_ch=16, lr=8.5742e-4, dropout_p=0.198, dice_weight=0.228`) was fixed before its single test-set evaluation.

## 2. Gitignored Large Artifacts (Attach via GitHub Release)
The following large binary/data artifacts are excluded by `.gitignore` and should be attached as assets to a GitHub Release (`v2.0-artifacts`):

| Artifact Path | Description | Status |
| :--- | :--- | :--- |
| `data/raw/sar_nxcl/` | Raw Chandrayaan-2 DFSAR L1A SLI & SRI tiles (ISRO PRADAN) | Raw external data |
| `data/processed_real/{train,val,test}.npz` | Frozen patch tensors + pixel masks (`9,828 / 2,040 / 2,018` patches) | Generated by `ingest_and_split.py` |
| `models_real/*.pth` | Trained checkpoints (`CustomCNN`, `ResNet_*`, `IceUNet_seed{42,123,2024}`, `resnet18_ssl_pretrained.pth`) | Generated by `train_all.py`, `train_unet.py`, `pretrain_ssl.py` |
| `reports/real/maps/test_strips_prob_uncertainty_slant_range.tif` | Stitched test-strip slant-range raster (`23.4 MB`, 468 GCPs) | Generated by `run_uncertainty_and_stitch.py` |
| `reports/real/maps/test_strips_prob_uncertainty_moon_stereo.tif` | TPS-warped Moon South Polar Stereographic GeoTIFF (`0.64 MB`, `25 m/px`) | Generated by `run_uncertainty_and_stitch.py` |

To publish a release with these artifacts once `gh` CLI is authenticated:
```bash
gh release create v2.0-artifacts \
  reports/real/maps/test_strips_prob_uncertainty_moon_stereo.tif \
  reports/real/maps/test_strips_prob_uncertainty_slant_range.tif \
  models_real/IceUNet_seed42.pth models_real/IceUNet_seed123.pth models_real/IceUNet_seed2024.pth \
  --title "IceShadowNet 2.0 Artifacts" \
  --notes "Pretrained U-Net checkpoints and QGIS-ready test-strip GeoTIFFs."
```
